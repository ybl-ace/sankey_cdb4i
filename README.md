# Categoría de Desempeño Insuficiente: Educación Básica (Cohorte 2016-2019)

Este repositorio contiene una visualización interactiva basada en un diagrama de Sankey, diseñada para ilustrar las transiciones de categoría de desempeño de los establecimientos de Educación Básica entre los años 2016 y 2019.

## Objetivos del Proyecto
* **Rastrear la movilidad educativa:** Mostrar visualmente cómo los establecimientos mejoran, empeoran o mantienen su nivel de desempeño a lo largo de 4 años.
* **Identificar focos críticos:** Destacar de manera prominente las trayectorias de rezago, específicamente el grupo de establecimientos que permanece en la categoría "Insuficiente" de forma reiterada.
* **Comunicación efectiva:** Presentar datos longitudinales complejos mediante un diseño limpio, minimalista y libre de ruido visual, optimizado para una lectura rápida.

## Origen de los datos
* **Los datos utilizados en el gráfico son públicos y fueron obtenidos desde https://informacionestadistica.agenciaeducacion.cl/#/bases
  
## Características Técnicas y de Diseño
* **Tecnología:** Desarrollado en HTML5 y JavaScript puro utilizando la biblioteca **Apache ECharts** para lograr curvas de flujo suaves y un renderizado orgánico.
* **Paleta Oficial:** Integración exacta de los colores institucionales por categoría para mantener la coherencia gráfica.
* **Interacción Narrativa:** Tooltips configurados para traducir los datos duros a frases de lectura natural al pasar el cursor sobre los flujos y nodos.

## Reconocimiento de Desarrollo Asistido por IA
El código, la estructura de datos y el diseño estético de esta visualización fueron construidos mediante un proceso de **programación colaborativa con Inteligencia Artificial**. Se utilizó un modelo de lenguaje avanzado como asistente técnico y analítico para la refactorización matemática de los márgenes, la limpieza semántica de los datos, la migración de la librería gráfica original (Plotly a ECharts) y la depuración del código final.

## Uso
El proyecto es estático y no requiere dependencias en el servidor ni compilación. Se puede visualizar en vivo mediante GitHub Pages o abriendo el archivo `index.html` localmente en cualquier navegador web moderno.
